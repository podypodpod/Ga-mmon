# pubeval's weights

`WT.race` and `WT.cntc` are the weights for Gerry Tesauro's pubeval, the race weights and the contact weights. They're unchanged from the copies at <https://www.cs.cmu.edu/afs/cs/project/connect/code/tesauro/>, next to his `pubeval.c` of February 1993. `uk.co.davidlomas.gammon.game.PubEval` is a Java version of that C.

Tesauro posted pubeval to rec.games.backgammon on 11 February 1993, "provided as a public service to the backgammon programming community", as a benchmark player. It has been used as one ever since. These files are covered by that, not by this project's MIT licence.
