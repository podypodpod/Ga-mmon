# Rule-based players from 2014

These are the players saved by the GA's runs in 2014, when a player chose its moves from a fixed list of rules (bear off, take a piece, double up a blot, block, ...) and set opening moves, with a gene for the chance of each.

That player was replaced by one that weighs features of the board (see `MoveChooser`), whose genes are different, so these files can't be loaded any more. They're kept as a record of those runs; the code that played them is in the git history before the change.
